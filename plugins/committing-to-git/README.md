# Committing to Git

Prepare and verify signed Git commits.

See the [plugin catalog](https://github.com/Hadden-Industries/plugins) for installation.

To request the corresponding MPL-2.0 source for the bundled helper, [open a source request](https://github.com/Hadden-Industries/plugins/issues/new) and include the installed plugin version. Bundled third-party licenses are in [notices/](notices/).
